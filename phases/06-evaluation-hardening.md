# Phase 06 — Evaluation, Hardening and Demo

## Goal

Prove the system works reproducibly and prepare it for a portfolio demonstration.

## Tasks

- Expand labelled fixtures to a useful, documented set.
- Report precision, recall, patch validity, latency and failure counts with raw denominators.
- Compare deterministic-only and LLM-assisted analysis.
- Test malformed events, prompt injection, oversized input, path traversal, unauthorized access and stale approvals.
- Add rate limits and operational kill switches where appropriate.
- Verify migration, backup and environment setup instructions.
- Deploy dashboard/worker only in an architecture compatible with private Ollama access.
- Capture real screenshots and record a truthful demo.
- Review README, architecture diagram, known limitations and setup instructions.

## Exit criteria

- Evaluation is reproducible and reports dataset scope.
- All required checks pass or are explicitly marked blocked.
- Security controls have test evidence.
- Demo path works end to end or clearly identifies mocked steps.
- No fabricated metrics or unsupported claims.
- Final handoff includes known limitations and resume-safe measured results.
